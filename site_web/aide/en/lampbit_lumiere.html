LAMP:bit: light level

Block: lampbit_lumiere

What is it for?

Measures the light received by the sensor of the LAMP:bit.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Plug it where a number is expected: in the ‘show’ block, or in a comparison with the ‘if’ block.

Good to know

  • The value goes from 0 (dark) to 1023 (very bright). The sensor is on pin P1.
  • In the simulator, the ‘Ambient light’ slider of the LAMP:bit section sets this value.

Example

The lamp turns on when it is dark (light below 350) and turns off when it is daylight.
